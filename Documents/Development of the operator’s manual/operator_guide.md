# Руководство оператора

## Версия интерфейса

1.5.0

## Аудитория

Операторы и техники учебного сервиса заявок.

## Предварительные условия

- Пользователь выполнил вход в систему.
- Открыт экран «Заявки».
- Пользователь обладает необходимыми правами доступа.



# Сценарий 1. Создание заявки без вложений

1. Открыть экран «Заявки».
2. Нажать кнопку Создать.
3. Заполнить поля Тема и **«Описание»**.
4. Не добавлять вложения.
5. Нажать кнопку **«Отправить»**.

### Результат

Отображается сообщение:

> «Заявка LAB-104 создана»

Нажать ссылку **«Открыть»**.

Убедиться, что открылась карточка заявки с присвоенным номером и статусом open.


# Сценарий 2. Добавление вложений
1. Создать новую заявку.
2. Добавить три файла PDF или PNG.
3. Попытаться добавить четвертый файл.

### Результат

Отображается сообщение:

> «Можно приложить не более 3 файлов».

Текст заявки остается в форме.

Удалить лишний файл и повторить отправку.



# Сценарий 3. Тайм-аут сети

После нажатия **«Отправить»** отображается сообщение:

> «Не удалось получить ответ. Проверьте список заявок перед повтором».

Если заявка найдена в списке, повторная отправка не требуется.

Если заявка отсутствует, сохранить введенный текст, обратиться в поддержку и не выполнять многократную отправку.



# Сценарий 4. Работа техника

1. Открыть фильтр **«Назначенные»**.
2. Найти назначенную заявку.
3. Нажать кнопку **«В работу»**.

Статус изменяется на **in_progress**.

После выполнения работы:

1. Нажать **«Отметить выполненной»**.
2. Заполнить обязательный комментарий.
3. Подтвердить завершение.

Результат — статус **resolved**.



# Сценарий 5. Ошибка доступа

При попытке открыть недоступную заявку отображается сообщение:

> «Нет доступа к этой заявке».

Нажать ссылку **«К списку»**.

Убедиться, что сведения о чужой заявке не отображаются.
