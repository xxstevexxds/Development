# Испытание руководства

## Вид испытания

Аналитическое испытание по модели интерфейса.

## Протокол

| Шаг | Ожидаемый результат | Наблюдение | Исправление |
|------|---------------------|------------|-------------|
| Создание заявки | После сохранения отображается номер заявки | Добавлено требование повторно открыть карточку | Исправлено |
| Добавление файлов | Четвертый файл отклоняется | Добавлено сообщение системы | Исправлено |
| Тайм-аут | Пользователь сначала проверяет список | Добавлено описание двух вариантов действий | Исправлено |
| Работа техника | Требуется комментарий перед завершением | Указан обязательный комментарий | Исправлено |
| Ошибка доступа | Пользователь возвращается к списку | Добавлена ссылка «К списку» | Исправлено |
